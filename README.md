# English practice — учебная страница

Статическая страница для занятий английским: две-три короткие практики, блок разговора вслух и вкладка «Прогресс» с оценками сложности.

## Как это обновляется

Страница — это один файл `index.html`. Изменения вносятся в него, дальше они публикуются автоматически.

## Приватность

На странице нет имён, фотографий, школы, ответов ребёнка и аналитики. Оценки сложности сохраняются только в браузере на устройстве и никуда не отправляются.

## Источники заданий

Все задания ведут на бесплатные материалы British Council (LearnEnglish Kids) и Cambridge English. Страница только направляет к ним.
