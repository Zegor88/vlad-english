# English practice — учебная страница

Статическая страница для занятий английским: короткие практики, блок разговора вслух и вкладка «Прогресс» с оценками сложности.

## Адрес

**https://zegor88.github.io/vlad-english/**

Ссылка постоянная: обновляется содержимое, адрес не меняется. Именно её стоит сохранить закладкой или иконкой на iPad.

## Как публикуется

Любое изменение `index.html` в ветке `main` автоматически публикуется workflow-ом `.github/workflows/deploy.yml` (GitHub Actions → GitHub Pages). Никаких ручных загрузок и никакого Cloudflare.

Проверить сборку: вкладка **Actions** в репозитории. Статус страницы — **Settings → Pages**.

## Структура

- `index.html` — вся страница целиком (один файл, без внешних зависимостей)
- `.github/workflows/deploy.yml` — публикация

## Приватность

На странице нет имён, фотографий, школы, ответов ребёнка и аналитики. Оценки сложности сохраняются только в браузере на устройстве (`localStorage`) и никуда не отправляются. Репозиторий публичный, но персональных данных в нём нет.

## Источники заданий

Все задания ведут на бесплатные материалы British Council (LearnEnglish Kids) и Cambridge English. Страница только направляет к ним — ответы проверяют сами ресурсы.
